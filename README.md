# Ascend Card Game

Jogo de cartas de duelo de criaturas. Este repositório concentra **regras aprovadas, motor de partida, interface e testes**.

Os dados das criaturas (fichas, cartas, artes e catálogo) são mantidos separadamente em [Catálogo SRD](https://github.com/george-vepo/Catalogo-SRD).

> Estado inicial: repositório recém-criado. A migração dos componentes será proposta em uma branch e pull request, sem alterar este README até aprovação.

**Privacidade:** nunca versionar mãos privadas, ordem oculta de montes, segredos ou checkpoints de partidas reais.
